# rtdc-toolbox

This repository provides a collection of Python tools for working with RT-DC files generated by deformability cytometry (DC). It uses the [`dclab`](https://dclab.readthedocs.io/en/stable/) library for working with `.rtdc` files and PyTorch for machine-learning-based classification. 

It works with `.rtdc` files segmented with ChipStream. The class information is stored in new `.rtdc` files using the following typical naming convention:

- `MySample.rtdc` : original `.rtdc` file
- `MySample_dcn.rtdc` : original `.rtdc` file segmented with ChipStream
- `MySample_dcn_cnt.rtdc` : classified with supervised ML  
- `MySample_dcn_klmn25.rtdc` : classified with classifier based of Kaliman et al. 2025 paper  
- `MySample_dcn_cnt.PNG` : Quality control report showing if values of measured class featues change during timecourse of experiment
- `MySample_dcn_cnt_classes.PNG` : Report showing examples of classified cells  

The `_cnt.rtdc` files link to the original file and contain classification metadata and class information stored in scalar RT-DC features such as `"userdef1"`, `"userdef2"`, etc. Typically, class info is stored as an integer number in `"userdef1"` and probability in `"userdef2"`. The actual `_cnt` extension is user-definable and should reflect the classifier name. See folder ['OutputExamples']('OutputExamples') for examples of PNG reports.

## Main Usage

### 1. Image viewer for RT-DC files

A simple and very useful viewer for quick inspection of recorded samples.  
If images are segmented, it can display event contours.  
If events are classified, it can also show class labels.

Usage:

- `rtdc_image_viewer.py`

### 2. Machine-learning framework for event classification

A lightweight PyTorch-based framework that helps you:

- build your own training dataset
- train a custom model
- classify events in RT-DC files

A basic model for classifying RBCs/WBCs/platelets/aggregates is already provided, together with the training dataset used to create it. For additional information about the ML framework, see [rtdc_toolbox_ml_framework.md](rtdc_toolbox_ml_framework.md).


Usage examples:

- `example-train_ml_model.py`  
- `example-classify_rtdc_ml.py`

### 3. WBC classification based on Kaliman et al. (2025)

We implemented WBC classification following the protocol described in:

Kaliman et al., *Automation and improvement of WBC mechanical profiling in deformability cytometry*, Biophysical Journal, 2025,  
DOI: 10.1016/j.bpj.2025.10.007

Usage:

- `example-classify_rtdc_WBC_klmn25.py`

### 4. RT-DC file analysis

A crucial step in the DC workflow is the quick inspection of recorded RT-DC files to verify experimental integrity (e.g., whether measured parameters remained stable during acquisition).

We provide a simple function that summarizes this information in a PNG image for quick review.

Usage:

- `example-analyze_rtdc.py`

## Function list

### `get_img_diff`
- **Purpose:** Returns the difference of two uint8 images without clipping (for preprocessing)
- **Main inputs:** two images of the same size
- **Output:** the difference of the images shifted for `background_subtraction_shift` above 0

### `preprocess_rtdc_image`
- **Purpose:** Preprocess a single RT-DC event image (background subtraction and cropping around the event)
- **Main inputs:** `dclab` RT-DC dataset and index of the event to preprocess
- **Output:** preprocessed image of the event

### `extract_preprocessed_images_from_rtdc_to_zip`
- **Purpose:** Export preprocessed event images from an `.rtdc` file into a ZIP (for building a training set)
- **Main inputs:** input `.rtdc` file, various parameters for defining which images to export and how
- **Output:** `None` (writes a ZIP with extracted images).

### `train_model`
- **Purpose:** Train a CNN classifier on a labeled dataset of *preprocessed* RTDC images 
- **Main inputs:** path to the training_set, path to the training results, CNN classifier and a number of other parameters
- **Output:** `None` (saves the model to the results folder along with some metadata and accuracy info)

### `classify_ds_ml`
- **Purpose:** Classify events in an already-open dataset using a saved PyTorch model.
- **Main inputs:** input `dclab` RT-DC dataset, path to the model and a number of other parameters
- **Output:** class labels, probabilities and metadata

### `classify_rtdc_ml`
- **Purpose:** Run `classify_ds_ml` on a `.rtdc` file and store results in a new `.rtdc`
- **Main inputs:** input `.rtdc` file, path to the model and a number of other parameters
- **Output:**  path to the newly written classified `.rtdc` file.

### `classify_ds_WBC_klmn25`
- **Purpose:** Run the Kaliman 2025 WBC (scikit-learn) classifier on an already-open dataset.
- **Main inputs:** input `.rtdc` file
- **Output:** class labels and metadata

### `classify_rtdc_WBC_klmn25`
- **Purpose:** Run classify_ds_WBC_klmn25 on a `.rtdc` file and store results in a new `.rtdc`
- **Main inputs:** input `.rtdc` file
- **Output:** path to the newly written classified `.rtdc` file.

### `analyze_rtdc`
- **Purpose:** QC: create a PNG report showing trends for selected features over time.
- **Main inputs:** input `.rtdc` file
- **Output:** path to the newly written PNG 

### `export_examples_of_cells_for_classes_in_rtdc`
- **Purpose:** QC: create a PNG report showing examples of cells in different classes.
- **Main inputs:** input `.rtdc` file
- **Output:** path to the newly written PNG 

### `save_features_to_rtdc`
- **Purpose:** Make a new `.rtdc` file containing new feature arrays + metadata and a basin reference linking back to the original 
`.rtdc` file.
- **Main inputs:** input `.rtdc` file, output `.rtdc` file, features to write
- **Output:** path to the newly written `.rtdc` file.

### `get_classes_from_rtdc`
- **Purpose:** Get class names from a `.rtdc` file metadata
- **Main inputs:** `.rtdc` file
- **Output:** dictionary mapping class id → class name



## Installation

If you already have a working standard `dclab` and `PyTorch` Python environment (see dependencies below), no additional installation is required — simply download the files and run them.

If you want to start from scratch:

1. Create a new Python environment. 

2. Install PyTorch with GPU support 

   If you don't need the machine learning components, you can skip this step.

   Visit https://pytorch.org/get-started/locally/, select your system configuration, copy the installation command, and run it in your console.  
   For our setup, the command was:

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
```
    
3. Install the remaining required packages:

```bash
pip install numpy opencv-python dclab tqdm matplotlib scikit-learn pillow
```

If the latest versions do not work, you can try the versions we used successfully:

```
Python        3.13.2
numpy         2.2.6
opencv-python 4.11.0.86
dclab         0.64.0
tqdm          4.67.1
matplotlib    3.10.3
scikit-learn  1.6.1
torch         2.7.0+cu126
torchvision   0.22.0+cu126
```

## Notes

rtdc-toolbox is based on the paper: Fajdiga Lebar et al., *Effects of intravenous lipid emulsions on Jurkat cells assessed using label-free deformability cytometry*, Scientific Reports, 2025.  https://doi.org/10.1038/s41598-025-33582-7

Please cite this paper if you find rtdc-toolbox useful.

The current version was rewritten from scratch with substantial assistance from AI. The scripts were tested on real RT-DC data and were found to work well in practice; however, since we do not fully understand every aspect of the AI-generated code, we cannot guarantee that it is entirely free of bugs.

The original implementation is available in the `legacy` folder.
